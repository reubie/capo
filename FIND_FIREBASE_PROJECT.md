# How to Find Your Firebase Project in Google Cloud Console

## The Issue
Your Firebase project "jiome-f9f77" might not be visible in the current project list. This could be because:
1. You're in a different organization/account
2. The project is in a different folder
3. You need to search for it

## Solution

### Step 1: Search for Your Firebase Project
1. In the "Select Resource" dialog, use the **search box**: "Search projects and folders"
2. Type: **jiome** or **jiome-f9f77**
3. The project should appear in the results

### Step 2: Check Organization/Account
1. Look at the dropdown at the top of the dialog
2. It currently shows: **jiomegroup.com**
3. Make sure this is the correct organization where your Firebase project is located
4. If you have multiple organizations, switch to the one containing your Firebase project

### Step 3: Alternative - Access via Firebase Console
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select project: **jiome**
3. Click the **gear icon** (⚙️) → **Project settings**
4. Scroll down to **Your apps** section
5. Click on your web app
6. Look for a link that says **"Open in Google Cloud Console"** or similar
7. This will take you directly to the correct project

### Step 4: Once You're in the Right Project
1. The project name should be: **jiome-f9f77** or **jiome**
2. You should see it in the top dropdown
3. Then proceed to **APIs & Services** → **Credentials** to edit the API key
